MANUAL BOOK

Aplikasi Sistem Pendukung Keputusan (SPK) Penyaluran Zakat

1. Pendahuluan

Aplikasi Sistem Pendukung Keputusan (SPK) Penyaluran Zakat adalah perangkat lunak yang dirancang untuk membantu dalam proses seleksi dan penentuan penerima zakat (mustahik) secara objektif dan terkomputerisasi. Aplikasi ini mengelola data mustahik, kriteria penilaian, subkriteria, serta melakukan perhitungan untuk menghasilkan rekomendasi penerima zakat terbaik berdasarkan kriteria yang telah ditetapkan.

2. Kebutuhan Sistem

  • Sistem Operasi: Windows 7, 8, 10, atau 11
  • Java Runtime Environment (JRE) minimal versi 8
  • Database: MySQL (via XAMPP atau sejenisnya)

3. Hak Akses dan Login

Untuk dapat menggunakan aplikasi, pengguna harus melakukan login terlebih dahulu:

  1. Buka aplikasi SPK Zakat.
  2. Pada halaman Login, masukkan Username dan Password yang valid.
  3. Klik tombol Login. Jika data benar, Anda akan diarahkan ke halaman Dashboard utama.

4. Fitur Utama dan Penggunaan

Aplikasi ini memiliki beberapa menu utama yang dapat diakses melalui sidebar di sebelah kiri layar:

4.1. Dashboard

Halaman utama yang menampilkan ringkasan informasi, seperti total mustahik, total kriteria, total penilaian, serta grafik atau rangking teratas dari calon penerima zakat.

4.2. Data Mustahik

Menu ini digunakan untuk mengelola data calon penerima zakat.

  • Tambah Data: Isi form (NIK, Nama, Jenis Kelamin, No HP, Alamat) dan klik tombol Simpan.
  • Ubah Data: Pilih data pada tabel, ubah informasi pada form, lalu klik Ubah.
  • Hapus Data: Pilih data pada tabel dan klik tombol Hapus.
  • Pencarian: Gunakan kolom pencarian di bagian atas tabel untuk mencari mustahik berdasarkan nama atau NIK.

4.3. Data Kriteria

Menu ini digunakan untuk mengatur kriteria penilaian (Penghasilan [0.25], Jumlah Tanggungan [0.20], Status Pekerjaan [0.15], Status Tempat Tinggal [0.12], Kepemilikan Aset [0.10], Kondisi Kesehatan [0.08], Jumlah Anggota Keluarga Yang Bekerja [0.05], Usia [0.05]).

  • Setiap kriteria memiliki Kode (misal: C1, C2), Nama Kriteria, Bobot (dalam persentase atau angka), dan Jenis (Benefit atau Cost).
  • Pengguna dapat menambah, mengubah, atau menghapus kriteria sesuai kebijakan penilaian.

4.4. Data Subkriteria

Subkriteria adalah rincian nilai dari masing-masing kriteria.

  • Pilih Kriteria terlebih dahulu.
  • Masukkan nama subkriteria dan nilai (rating) yang sesuai.
  • Gunakan tombol aksi (Simpan, Ubah, Hapus) untuk mengelola data.

4.5. Penilaian

Proses pemberian nilai kepada setiap mustahik berdasarkan kriteria yang ada.

  • Pilih nama mustahik dari daftar.
  • Isi/pilih nilai untuk setiap kriteria berdasarkan subkriteria yang telah dibuat.
  • Klik Simpan untuk menyimpan data penilaian.

4.6. Hasil SPK

Menu ini menampilkan hasil perhitungan Sistem Pendukung Keputusan (menggunakan metode SPK tertentu yang ditanam dalam sistem).

  • Sistem akan melakukan normalisasi dan perhitungan akhir.
  • Hasil akhir akan berupa daftar mustahik beserta Nilai Preferensi dan Rangking.
  • Mustahik dengan nilai atau rangking tertinggi direkomendasikan sebagai prioritas penerima zakat.

4.7. Laporan

Fitur untuk mencetak atau mengekspor data laporan yang dibutuhkan oleh pengurus atau lembaga amil zakat.

  • Pilih jenis laporan (Laporan Data Mustahik, Laporan Hasil Keputusan, dll).
  • Klik tombol Cetak atau ekspor untuk menyimpan laporan (biasanya ke format Excel atau PDF).

5. Penutup

Demikian manual book penggunaan Aplikasi Sistem Pendukung Keputusan Zakat ini. Pastikan Anda melakukan backup database secara berkala untuk menjaga keamanan data. Jika mengalami kendala teknis, silakan hubungi administrator sistem Anda.
